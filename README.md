# Higher or Lower - Dice Webgame

A vibrant, 3D-enhanced dice game built with Three.js. Guess if the sum of two dice will be higher, lower, or exactly 7.

## Features
- **3D Dice Physics**: Realistic dice rolls with custom reveal animations.
- **Premium VFX**: Confetti on wins, pulsing red vignettes on losses, and glassmorphic UI.
- **Dynamic Shop**: Recharge your bankroll to keep the stakes high.
- **Responsive Design**: Playable on mobile and desktop.

## Technologies Used
- **HTML5/CSS3**: Modern layouts and glassmorphic aesthetics.
- **JavaScript**: Core game logic and state management.
- **Three.js**: WebGL-based 3D rendering for the table and dice.

## How to Play
1. **Start Game**: Click the "Start Game" button on the home screen.
2. **Place Bet**: Enter your bet amount (Minimum 300).
3. **Make a Guess**: Choose "Higher", "Lower", or "Exactly 7".
4. **Roll**: Confirm your guess and watch the dice fly!
5. **Win/Loss**:
   - **Higher**: Sum is > 7.
   - **Lower**: Sum is < 7.
   - **Exactly 7**: Sum is 7 (Highest payout).

## Installation
Just open `index.html` in any modern web browser. No server-side setup required.
